# Remotion Reel Maker

## Setup

De Remotion componenten zijn geconfigureerd en klaar voor gebruik.

## Gebruik

### 1. Remotion Studio starten

```bash
npm run remotion:studio
```

Dit opent de Remotion Studio waar je je reel kunt previewen en aanpassen.

### 2. Video renderen

```bash
npm run remotion:render
```

Dit rendert de video naar een MP4 bestand.

## Bestanden

- `components/MyReel.tsx` - De hoofdcomponent voor de reel
- `components/RemotionRoot.tsx` - Root component met Composition configuratie

## Aanpassen

Je kunt de `MyReel` component aanpassen om verschillende animaties, tekst, of visuals toe te voegen. Gebruik de Remotion API voor geavanceerde animaties.
